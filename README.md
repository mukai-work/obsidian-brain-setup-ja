# obsidian-brain-setup-ja

Obsidianを「第二の脳」としてセットアップするための完全ガイドとフォルダ構造・テンプレート・X連携設定を自動生成するスキルです。

## 使い方

```
/obsidian-brain-setup-ja
```

## このSkillでできること

- ✅ 用途に合わせたフォルダ構造の提案
- ✅ デイリーノート・アイデア・X連携用テンプレートの生成
- ✅ おすすめプラグインのリストとインストール手順
- ✅ XのポストをObsidianに保存する方法
- ✅ ObsidianのメモをXポスト用に変換する方法
- ✅ 続けるための3つのルール

## 対象ユーザー

- Obsidianを入れたけど何から始めればいいかわからない人
- ノートアプリを試したけど続かなかった人
- XとObsidianを連携して情報を一元管理したい人
- AI（Claude Code）と組み合わせて思考を自動整理したい人

## インストール

```bash
cd your-project/.claude/skills/
git clone https://github.com/mukai-work/obsidian-brain-setup-ja.git
```
